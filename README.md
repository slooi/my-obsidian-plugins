# my-obsidian-plugins
A personal collection of features which extend obsidian functionality

### Feature List
- images
  - right click copy img to clipboard
- insert tabs when tab key is pressed


### How to develop more features
- Run `pnpm run dev`
- Implement feature in main.ts
- In obsidian open the cmd platte (`Ctrl+P`) and run `Reload app without saving` to test feature

source: https://docs.obsidian.md/Plugins/Getting+started/Build+a+plugin
